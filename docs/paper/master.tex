\section*{Recent Changes}
\begin{itemize}
  \item 2026-02-05: Added a minimum m4ri-trials filter for best-codes publishing
    (enforcing max(best\_trials, 500k)) to prevent low-trial entries from
    reappearing in the website tables. The publish script now supports
    \texttt{--min-m4ri-trials}.
  \item 2026-02-05: Publishing runs now use a 50k m4ri-trials floor
    (\texttt{--min-m4ri-trials 50000}) to restore previously listed codes
    while longer refinements proceed.
  \item 2026-02-05: Added a best-codes publishing exemption for length
    $n=252$ so shorter codes can appear on the website with fewer trials
    when desired (\texttt{--min-m4ri-trials-exempt-n 252}).
\end{itemize}
